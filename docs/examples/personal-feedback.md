# 个人反馈示例

以下平台和信息均为虚构示例。

## 用户原话

> 示例出行的订单结束后，司机还能一直发推销消息。我已经遇到三次了，找不到单独屏蔽这类消息的开关。如果能把行程消息和营销消息分开，并提供一键屏蔽，会好很多。

## 反馈速览

- 目标平台：示例出行
- 产品区域：订单消息与通知设置
- 类型：体验问题 / 功能建议
- 场景：订单结束后收到与行程无关的营销消息
- 频率：用户亲历三次
- 影响程度：中
- 用户期望：分离行程和营销消息，并支持一键屏蔽

## 情绪与满意倾向

- 情绪强度：3/5
- 满意倾向估计：3/10
- 置信度：中
- 依据：用户明确表示重复遇到、找不到控制开关，并给出具体期望；这只是模型估计，不是调查分数。

## 事实分层

- 用户亲历：用户表示订单结束后收到司机发送的营销消息，共遇到三次。
- 已核实事实：尚无；需要核实平台当前消息设置和官方反馈入口。
- 待核实：营销消息是否使用订单联系通道、其他用户是否也遇到。
- 模型推断：当前可能缺少按消息用途区分的用户偏好控制。

## 建议

1. 近期：在订单消息中增加“举报为营销 / 不再接收此类消息”操作。验收标准：用户操作后不再收到同一发送方的非行程消息。
2. 下一版本：将行程必需通知和营销消息分开授权。验收标准：关闭营销消息不影响接单、到达和安全通知。
3. 长期：建立订单联系通道的用途检测和违规处置机制。验收标准：用户能查看举报状态，重复违规发送方受到限制。

## 最终发送稿

```text
主题：【产品反馈】订单消息：建议分离行程通知与营销消息

您好，

我是贵平台的真实用户。订单结束后，我仍收到司机发送的非行程推销消息，已实际遇到三次。在当前设置中，我没有找到只屏蔽此类营销消息、同时保留必要行程通知的方式。

这会增加消息干扰，也让我难以判断哪些通知与订单安全或服务真正相关。

建议：
1. 增加“举报为营销 / 不再接收此类消息”操作；
2. 将行程必需通知与营销消息分开授权；
3. 为举报提供可追踪状态，并对重复违规发送方采取限制。

希望贵团队告知该反馈是否已记录、对应反馈或工单编号，以及后续状态可在哪里查看。

谢谢您阅读并处理这条反馈。
```
